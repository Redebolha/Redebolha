# 🎯 Rebalanceador de Carteira - Investimento 25/25/25/25

Um programa interativo para gerenciar e rebalancear sua carteira de investimentos seguindo o plano de alocação estratégica: **25% Renda Fixa | 25% Ações Brasil | 25% Ativos Exterior | 25% Imóveis**.

## 📊 Características

✅ **Adicionar Ativos** - Registre suas ações, fundos, ETFs e imóveis  
✅ **Análise de Alocação** - Veja graficamente como sua carteira está distribuída  
✅ **Rebalanceamento Inteligente** - Receba recomendações de compra/venda  
✅ **Persistência de Dados** - Seus dados são salvos automaticamente no navegador  
✅ **Exportação** - Exporte relatórios em JSON para análise posterior  
✅ **Responsivo** - Funciona perfeitamente em desktop, tablet e mobile  

## 🚀 Como Usar

### 1. Adicionar Ativos

1. Preencha o nome do ativo (ex: GGRC11, MXRF11)
2. Selecione o tipo:
   - **Ações do Brasil** - Ações brasileiras
   - **Renda Fixa** - Títulos, CDBs, Tesouro Direto
   - **Ativos Exterior** - ETFs internacionais, ações estrangeiras
   - **Imóveis** - Fundos imobiliários, imóveis físicos
3. Informe a quantidade
4. Informe o preço unitário
5. Clique em "Adicionar"

### 2. Analisar Alocação

O programa mostra automaticamente:
- **Gráfico de Alocação Atual** - Sua distribuição real
- **Gráfico de Alocação Alvo** - O objetivo (25/25/25/25)
- **Patrimônio Total** - Valor total da carteira
- **Taxa de Desempenho** - Ganho/perda percentual

### 3. Rebalancear

As ações de rebalanceamento aparecem automaticamente:
- 📈 **COMPRAR** - Categorias abaixo do alvo
- 📉 **VENDER** - Categorias acima do alvo
- ✅ **BALANCEADO** - Quando a carteira está próxima do alvo

## 📋 Exemplo de Dados

Clique em "Carregar Exemplo" para ver dados pré-preenchidos com:
- GGRC11 (131 unidades)
- MXRF11 (102 unidades)
- CPTS11 (110 unidades)
- SPX11 (11 unidades - ETF internacional)
- JEPQ (Tesouro Direto)

## 💾 Salvamento de Dados

Seus dados são salvos automaticamente no localStorage do navegador. Para fazer backup:
1. Clique em "Exportar Dados"
2. Um arquivo JSON será baixado com toda sua carteira
3. Você pode carregar este arquivo mantendo uma cópia segura

## 📝 Notas Importantes

1. Os preços são inseridos manualmente - atualize regularmente
2. O rebalanceamento é uma recomendação, não obrigação
3. Considere impostos (IR, IOF) ao executar operações
4. A alocação 25/25/25/25 é um plano base, ajuste conforme sua tolerância ao risco
5. Faça backups regulares exportando seus dados

## 🔐 Privacidade

- Todos os dados são armazenados apenas no seu navegador
- Nenhuma informação é enviada para servidores
- Para limpar dados, use "Limpar Tudo" ou limpe o cache do navegador
